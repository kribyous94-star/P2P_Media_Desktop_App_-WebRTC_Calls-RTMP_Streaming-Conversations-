# Correctifs de sécurité du 30 octobre 2026

**CVE-2026-111497** (Node.js, Brotli) : la version embarquée du décodeur Brotli de Node.js contient une écriture hors limites. Elle peut provoquer un déni de service ou une exécution de code à distance. Les versions corrigées sont Node **22.23.4**, **24.22.1** et **26.12.1**. Node 20 est en fin de vie et ne reçoit pas de correctif.

Ce dépôt fixe Node `24.22.1` dans `.nvmrc` et `engines.node` vaut `^22.23.4 || ^24.22.1 || >=26.12.1` (ancienne valeur : `>=20.0.0`). Le README est mis à jour.

**CVE-2026-109618 / CVE-2026-109619** (PHP) : ce dépôt ne contient pas de PHP. Le PHP du VPS est déjà corrigé par le paquet Ubuntu `8.3.6-0ubuntu0.24.04.13`.

Le [rapport global du VPS](https://github.com/kribyous94-star/ummah-verse/blob/main/docs/VPS_SECURITE_2026-10-30.md) détaille la bascule, les validations et le retour arrière.
